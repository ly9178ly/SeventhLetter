## 不变的事实

三年前旧馆搬迁当晚，林知秋留在档案室整理将被丢弃的学生来信。她提前反映过门锁故障。21:17，周启明未核实档案室就锁上通道；志愿者主角听见三下敲击，接受了“管道声”的解释，签下清场确认。之后发生电路故障和烟情，林知秋被发现时已死亡。

最初寻人启事仍在校园传播，但后续通报已明确死亡事实。第二章必须让玩家读到通报，不能用含糊措辞吊着她的生死。主角没有完全失忆：一直回避那晚的具体记忆，也曾写下未寄出的说明。

周启明补写登记并修改合影；摄影志愿者沈予压下过录音，今晚安排部分重演；主角在书面说明里否认异常声音。三人分别承担自己的行为责任，不让主角承担全部事故因果，不将承认责任写成请求死者原谅的交易。

## 可解释与仍不确定的部分

沈予通过旧维修通道在窗外敲击，用便携音箱安排部分声音；匿名消息、裁年复印件、登记中的未来时间和预印信封可以解释。合影里第四道影子属于被抹掉的林知秋，而“原图也有影子”并非超自然证据。

便携音箱已关闭后的一句话、结尾照片或字迹变化没有定论。玩家可以记录异常，但不能把异常当作已经证明的事故原因。正文不出现必须完全随机或必须相信鬼才能通关的条件。

## 推理规则

| 核对 | 精确证据组合 | 正确判断/持久化标记 |
| --- | --- | --- |
| 身份 | 合影原件 + 清场确认单 | 主角是签过清场确认的志愿者 / identity |
| 原因 | 第二封信 + 事故后续通报 | 已知门锁故障未处理，加上未核查清场，延误发现 / cause |
| 听见 | 第六封信 + 当晚录音 | 主角听见声音，却接受解释而未核查 / witness |

必须实际取得选中证据；组合顺序无关；多选、重复、不相关或错误判断不产生标记。不扣分、不锁死，可重试、回看档案和补搜。推理板在第二章起开放；部分证据需第三章取得。

- 空白收件人：第三章或写信处主动选择否认，必须再次确认；并非一次点错即触发。寻人启事上出现主角，姓名空白。
